## Why this paper matters

Raft is one of those papers that feels approachable until you try to encode the transitions precisely. Implementing it is a fast way to discover how many details sit behind the word understandable.

## Implementation pressure points

- Election timing is conceptually easy and practically delicate.
- Log matching rules force discipline into every append path.
- State transitions need to be explicit or bugs get buried in optimistic assumptions.

## Personal note

This implementation has been especially useful for improving how I think about failure modes, especially when a system is technically healthy but still carrying stale assumptions about leadership.
